# 女帝篇 — 和谐人名还原工具 v3.7

还原《女王的游戏：盛世天下》女帝篇中被和谐的唐朝历史人名。

游戏中的大量历史人名被谐音替换（李唐皇室改姓"礼"、武氏改姓"伍"、国号"唐"改为"盛"、首都"长安"改为"盛安"等），本工具通过二进制级别的等字节替换，将所有名称还原为历史原名。

**设计理念**：保持游戏原名，仅替换姓氏和特定人名。例如"伍元照"还原为"武元照"（保持游戏原名），而非"武则天"（历史名）。

## 使用方法

本工具包含两部分：

| 功能 | 说明 | 文件 |
|------|------|------|
| **文件替换** | 替换游戏配置文件中的静态文字（菜单、对话、物品描述等） | PS1 启动器 / Node.js 脚本 |
| **内存补丁** | 游戏运行时实时替换视频字幕中的和谐名称 | `memory_patch.exe` |

> **说明**：游戏中的文字分为两部分——配置文件中的**静态文字**（菜单、对话、物品介绍等）和加密 `.k` 文件中的**视频字幕**。文件替换可解决静态文字，但视频字幕使用 AES 加密（密钥未知），无法直接修改文件，需要在游戏运行时通过内存补丁实时替换。
>
> **风险提示**：内存补丁通过读写游戏进程内存实现替换，存在导致游戏崩溃的风险（尤其是切换章节时）。请自行决定是否使用。

### 文件替换（菜单、对话等）

#### 方式一：双击运行（推荐，无需任何依赖）

1. 下载本仓库：**[点击下载 ZIP](https://github.com/shin4/empress-name-restore/archive/refs/heads/master.zip)**
2. **解压 ZIP 到任意文件夹**（不能直接在压缩包内运行）
3. 进入解压后的文件夹，双击 **`启动还原工具.bat`**
4. 工具会自动搜索 Steam 游戏目录，显示菜单：
   ```
   [1] 一键替换（人名 + 字幕）
   [2] 一键验证（人名 + 字幕）
   [3] 一键还原（人名 + 字幕）
   [4] 退出
   ```
5. 输入 `1` 回车即可同时完成人名和字幕的替换

> 首次运行自动备份原始文件，可随时通过菜单 `[3]` 还原。

#### 方式二：Node.js 脚本（适合开发者）

需要 [Node.js](https://nodejs.org/)，将脚本文件放入游戏目录后运行：

```bash
# 人名替换
node replace_names.js    # 替换
node verify_names.js     # 验证
node restore_names.js    # 还原

# 字幕替换
node replace_subtitles.js    # 替换
node verify_subtitles.js     # 验证
node restore_subtitles.js    # 还原
```

### 内存补丁（字幕实时替换）

游戏的字幕文件使用 AES 加密（`.k` 格式），无法直接修改文件。内存补丁通过在游戏运行时直接修改进程内存来实现字幕替换。

#### 使用步骤

1. **先启动游戏**，进入任意章节
2. 双击 **`release/memory_patch.exe`**（会弹出 UAC 权限提示，点击"是"）
3. 脚本后台自动运行，每 3 秒扫描一次游戏内存
4. 发现和谐名称立即替换为历史原名
5. 切换章节时自动检测新加载的字幕并替换
6. 游戏退出时脚本自动退出，或按 `Ctrl+C` 手动退出

#### 工作原理

```
游戏启动 → 加载 .k 文件 → AES 解密 → 字幕进入内存
                                              ↓
memory_patch.exe → 扫描内存 → 查找 "礼治" 字节 → 替换为 "李治" → 写回内存
                                              ↓
                                        字幕显示历史原名
```

#### 注意事项

- **必须以管理员权限运行**（需要读写其他进程内存）
- **先启动游戏，再启动补丁**；如果游戏重启，需要重新运行补丁
- 替换对定义在 `release/name_mapping.json`，可自行编辑
- 如果杀毒软件误报，请添加信任（内存读写操作可能触发启发式检测）

## 工作原理

### 文件替换

《女王的游戏：盛世天下》女帝篇基于 Unity 引擎，使用 protobuf 格式存储游戏数据。人物名称存储在 `TextClient*.pbin` 这类 **明文 protobuf** 文件中（共 80 个），而游戏逻辑配置（`CharacterConfig.pbin` 等 44 个文件）使用 AES 加密。

关键架构：游戏采用 **ID 与文本分离** 的设计——加密的 Config 文件只存储结构化数据和 ID 引用（如 `TID_CharacterConfig_519619`），所有显示文本（包括人名）都在明文的 TextClient 文件中。因此只需修改明文文件即可完成全局替换。

所有 23 对替换均为 **等字节替换**（UTF-8 编码下新旧名长度相同），不会破坏 protobuf 的 varint 长度字段，保证游戏正常解析。

### 内存补丁

字幕文件（`.json.k`）使用腾讯 TBU 框架的 AES 加密（TBUAESv1），加密密钥未知，无法解密修改。游戏运行时，字幕以 UTF-8 字符串形式存在于进程内存中。内存补丁通过 Windows API 直接读写游戏进程内存，实现运行时替换。

## 自定义

编辑 `name_mapping.json` 可增删替换对：

```json
{
  "replacements": [
    { "from": "伍元照", "to": "武则天", "desc": "女主角本名" }
  ]
}
```

所有替换必须满足等字节条件（UTF-8 编码下 `from` 和 `to` 字节数相同）。

## 构建 .exe

如果需要自行构建 `memory_patch.exe`：

```bash
# 安装 PyInstaller
pip install pyinstaller

# 打包
pyinstaller --onefile --uac-admin --add-data "name_mapping.json;." --name memory_patch memory_patch.py

# 输出在 dist/memory_patch.exe
```

或直接运行 `build.bat` 一键打包。
